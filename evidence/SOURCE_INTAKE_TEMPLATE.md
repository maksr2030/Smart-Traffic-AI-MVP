## Required safeguards

- Never infer a missing legacy number from sequence alone.
- Never convert semantic similarity into historical-number proof.
- Never double-count a capability merely because a stronger source was found later.
- Preserve the original artifact and its fingerprint before normalizing extracted records.
- Separate documented capability evidence from MVP implementation evidence and production verification.
